# 🤖 Ассистент первичного анализа брифа на разработку СППР

Telegram-бот для системных аналитиков и архитекторов ИИ. Принимает голосовое описание задачи и фотографию рукописной схемы, а возвращает структурированный аналитический отчёт и сгенерированное изображение архитектуры системы поддержки принятия решений (СППР).

## 🚀 Возможности

- 🎤 Распознавание русской речи (Whisper Large v3 через Groq API)
- 🧠 Мультимодальный анализ: извлечение требований, проверка правил, определение типа решателя (экспертная / нечёткая / нейро-нечёткая система)
- 🖼️ Генерация архитектурной диаграммы СППР (Pollinations.ai)
- 💬 Работа в интерфейсе Telegram (принимает голосовое + фото, отдаёт текст + картинку)

## 🛠️ Используемые технологии и сервисы

| Компонент          | Инструмент                                   | Стоимость |
|--------------------|----------------------------------------------|-----------|
| Распознавание речи | Groq (Whisper Large v3)                      | бесплатно |
| Анализ текста+фото | OpenRouter (Gemini Flash 1.5)                | бесплатно |
| Генерация схем     | Pollinations.ai (модель Flux, без водяного знака) | бесплатно |
| Хостинг            | Любой VPS / компьютер (только Python)        | от 0 руб  |

## 🔧 Структура проекта
   ```text
AIarchFirstSt_bot/
            ├── .env                 # секретные ключи (не хранить в репозитории)
            ├── requirements.txt     # зависимости
            ├── config.py            # загрузка настроек
            ├── main.py              # точка входа, запуск бота
            ├── handlersTG.py          # обработка сообщений Telegram
            ├── utils.py             # вспомогательные функции (скачивание, кодирование)
            └── services/
                ├── stt.py           # распознавание речи (Groq)
                ├── analyzer.py      # мультимодальный анализ (Gemini Flash)
                └── image_gen.py     # генерация изображений (Pollinations)
   ```
## 📦 Установка и запуск

1. **Клонируйте репозиторий** или создайте структуру проекта согласно описанию.
2. **Установите Python 3.10+** и создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate     # Linux / Mac
   venv\Scripts\activate        # Windows
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
4. **Получите API-ключи**:
- Telegram-бота: @BotFather
- Groq: console.groq.com
- OpenRouter: openrouter.ai/keys
5. **Создайте файл** .env в корне проекта со следующим содержимым:
   ```ini
    TELEGRAM_BOT_TOKEN=ваш_токен
    GROQ_API_KEY=gsk_...
    OPENROUTER_API_KEY=sk-or-v1-...
6. **Запустите бота**:
   ```bash
   python main.py 
7. В Telegram отправьте боту **одновременно** голосовое сообщение и фото схемы.
